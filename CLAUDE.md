# QET Football

Match predictor and team balancer for a 6v6 friends' football group. See README.md.

## Working rules

- Always describe the planned change and wait for the user's confirmation before writing or changing code.
- Real match data (`data/matches.csv`) contains friends' names and is git-ignored: never commit it.

## Commands

- Setup: `pip install -r requirements.txt` (the project is not installed as a package)
- Run: `python qet.py <command>` from the repo root
- Tests: `pytest`
